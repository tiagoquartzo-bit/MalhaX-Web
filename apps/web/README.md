# Painel web

Área do gestor, despacho e suporte. Módulos previstos: login e controle de acesso; cadastro/aprovação de motoristas e veículos; clientes e pedidos; produtos/volumes e códigos; planejamento de viagens/paradas; mapa e acompanhamento em tempo real; comprovantes/ocorrências; indicadores e fechamento.

Interface não concede autorização: todas as consultas e mutações precisam respeitar as políticas do backend. Nunca incluir chave Supabase `service_role` no bundle do navegador.
